孕育与诞生 — 可通关矩形灰盒

打开 Assets/TGJ/Scenes/Graybox.unity，点击 Unity Play。
Windows 可执行版本位于 Builds/Windows/TGJ.exe。

UI 已迁移为场景中的 GameUI Canvas 和 34 个可编辑界面预制体。
停止 Play 后可直接在 Scene 中拖动 Rect Transform、替换 Image、修改 Text。
详细操作见项目根目录《UI编辑说明.txt》。顶部 TGJ > UI > Select Scene Canvas 可快速选中 Canvas。
界面资产位于 Assets/TGJ/UI/Prefabs；运行时不重建静态界面或覆盖你的排版。

操作
鼠标点击人物、物品和界面按钮。空格/回车推进当前对话，首次点击显示完整句子。
对话在右侧纵向栏中累积显示，滚轮可直接回看；提供自动播放、快进、隐藏与 Log。
电话话题、C 分支与结局选项在右侧竖排。序幕引文与署名一起渐显，停留后一起渐隐；点击继续可提前淡出。
Esc 打开暂停菜单。设置包含音量、文字速度、全屏与减弱动效。
已解锁的场景可通过右上角前后箭头循环切换，地图也可直接跳转。
记忆物品可拖到场景内，也可以先点物品再点场景。点击已放入的物品即可取回。
彩蛋放入独立收藏背包，不能拖出，不参与结局条件。

临时设计（尚非正式策划）
解锁顺序：音乐厅 → 汽车旅馆 → 快餐店 → 教室。解锁后自由往返。
电话与钱包暂作工具；拍照为可选记录，不影响结局。
进入回忆时获得五件记忆物品：门票、杂志、消毒酒精、钥匙、旧书。
汽车旅馆占位对话给予两件未命名物品，并解锁快餐店。
快餐店占位对话给予两件未命名物品，并解锁教室。
教室占位对话给予一件未命名物品。
本灰盒需要十件记忆全部归位，回音乐厅点击未命名角色后可选择结局一或二。
第一幕的选择仅记录倾向，最终可作不同决定。
通关一、二后，开始新周目获得“没有递出的钱”，最终出现隐藏结局选项。
归位是已印证记忆的持久标记，取回不清除。错放不惩罚、不消耗，不解锁场景。

编辑内容
Assets/TGJ/Resources/TGJ/Catalog.asset：ScriptableObject 配置，包括场景、物品、获得规则、成就及文本。
Assets/TGJ/Resources/TGJ/Story.yarn：实际由 Yarn 执行的剧情节点，可直接改写文本。
Assets/TGJ/Resources/TGJ/Content.json：创建 Catalog 的种子配置。
修改种子配置后运行 TGJ > Reload Story Content 更新 Catalog。
重建场景工具已移到 TGJ > Legacy；不要用它做日常 UI 排版，它会重建场景。
不要在未保存场景中运行重建；已有未保存修改时工具会拒绝。
逻辑场景由一个启动 Unity 场景承载，四个地点由配置切换。

验证
进入 Play 后，TGJ > Run Flow Smoke Tests 会在独立 TGJ_TEST_ 存档中走完甲、乙、C两分支和全部结局。
测试包含取名、锁定选择、无副作用重看、错误/正确放置、取回、场景解锁、收藏、存读档、隐藏结局。
结果：TestResults/graybox-smoke.txt。结束后返回主菜单，不覆盖玩家正常存档。
TGJ > Build Windows Player 生成 Windows 版本。

持久化
自动进度、一个手动槽、全局结局与成就、设置分别以 PlayerPrefs 保存。
旧存档首次读取会移除已撤下的自拟聊天文本，保留原稿记录、姓名、选择和进度。
键名前缀 TGJ_GRAYBOX_V1_。清除跨周目操作需要确认，清除结局与成就，不删除普通存档。
新游戏清空当周目的收藏、物品位置与归位进度，保留跨周目记录。
