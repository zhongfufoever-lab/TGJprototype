# 青灰雾紫纸张 UI · Unity 交付包

本包对应你选中的最新第 3 张配色（2C），先完成 **无字静态页面**。

## 直接使用

1. 将整个 `GameUI_Handoff` 文件夹放进 Unity 项目根目录下的 `Design/` 中。应形成 `项目/Design/GameUI_Handoff/`，它与 `Assets/`、`Packages/`、`ProjectSettings/` 位于同一个项目内。不要把整个交付包直接拖进 Assets，以免把参考图和说明一并带入构建。
2. 在本机 Codex 中打开这个 Unity 项目根目录。
3. 将 `Prompts/01_静态页面_Codex提示词.md` 的全文发给 Codex，同时指向 `Reference/selected_2C.png`。无需让另一个 Codex 重新猜测我们之前的聊天记录。
4. 让 Codex 先创建独立展示场景和 UI Prefab，执行构建菜单，并预览 1920×1080。没有 Unity 编辑器控制能力时，按它交付的菜单在 Unity 中运行；这不要求先配置 Unity MCP。
5. 确认无字静态页后，再用 `Prompts/02_接入游戏_后续提示词.md` 接入真实功能。第二阶段并未包含在第一阶段的任务中。

## 包内有什么

- `Reference/`：选中的合成效果图，只用于对照。
- `Textures/Paper/`：4 张未经改动的真实纸张照片：卡纸、横线皱纸、方格纸、奶油皱纸。
- `Art/`：10 张原游戏透明 PNG，包含页面需要的场景与物品，以及额外备用美术；均未重绘。
- `Specs/layout_1920x1080.json`：35 个分层元素的近似布局、配色与显示尺寸。
- `Specs/asset_manifest.json`：每张素材的尺寸、透明边距与用途。
- `Specs/visual_spec.md`：Unity 视觉实现与验收说明。
- `Prompts/`：可直接复制的本机 Codex 任务提示词。
- `SOURCES.md`：纸张来源与素材类型说明。

## 素材状态

这是一套 **重建所需的素材与实施规格**，不是已验证的 Unity 工程、UnityPackage、PSD 或从效果图自动拆出的透明切片。纸张照片已经齐备；圆角、轻微纸边、阴影、头像占位和方格层由 Unity 中的 UI 对象、蒙版或自定义 Graphic 拼装。无需再让图像模型重画页面。

效果图不是原生分层文件；其中的闭合钱包、票面等与原游戏 PNG 有细微差异。实际落地以用户原 PNG 的内容、比例、色彩为准。原角色头像未提供，所以头像仅是可替换的无身份占位形状。

坐标来自人工测量，适合搭建起点。不能承诺逐像素复刻；最后应在 Unity 中与参考图对照微调。此包没有改动你的 Unity 工程，也尚未在你的项目中运行。
