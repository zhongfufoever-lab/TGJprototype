## 布局与层级

以 `Specs/layout_1920x1080.json` 的坐标、尺寸、层级顺序为准。它描述 1920×1080 的逻辑设计画布；若文件使用左上角为原点，在 Unity 中要正确转换坐标。推荐顶层子对象使用左上锚点与左上 Pivot，`anchoredPosition = (x, -y)`，`sizeDelta = (width, height)`。若有旋转，先确认规格中的正方向再转换，不要把时针方向弄反。

用一个独立的 UGUI Canvas 搭建，优先 `Screen Space - Overlay`，参考分辨率 1920×1080。先验证 16:9 的 Game 视图，避免把逻辑坐标误当成当前 Editor 窗口像素。非 16:9 情况保持整套构图等比，必要时留边，不拉长场景或纸张。视差本轮不实现。

建议结构如下；可按项目规范调整文件名，但各层必须独立可选中、移动和替换：

- `PaperCollageUIRoot`
  - `Background`：深蓝灰底与轻微纸张纹理。
  - `TopBar`：上方细分隔线、左上状态圆点、空白纸条标签、右上五个空白纸条按钮外观。
  - `InventoryPanel`：青灰卡纸底、空白标题纸条、雾紫页签、六件原游戏物品、底部空白奶油纸条。
  - `SceneFrame`：底层衬纸、方格纸、音乐厅 PNG。
  - `DialoguePanel`：青灰卡纸底、横线皱纸、顶部抬起的空白奶油纸条、头像占位、雾紫选择条。
  - `OverlayRoot`：空节点，供后续真实游戏接入。

左右栏高度、宽度、对齐和中央场景区域必须按规格落实，不能因照片尺寸或自动布局组件而变形。不要让 `ContentSizeFitter`、`LayoutGroup` 等在不知情的情况下重排设计坐标。库存物品要自然摆在卡纸上，**不要加格子边框、背景按钮块、虚线空槽或锁图标**。物品倾斜、缩放和选中装饰只在规格要求的范围内使用。

## 材质与照片处理

1. **用照片做纹理，用 UI 代码做形状。** 卡纸圆角、轻微毛边、纸条边界和层叠阴影可用 UGUI Mask、自定义 `Graphic` 或项目内的轻量 UI Shader 实现，不需要再生成图片，也不要以“没有现成透明切图”为由停止。
2. 主界面是固定构图，优先简单稳定的图片层与轮廓。可复用的按钮纸条或卡纸底可做成 Prefab；需要变宽的边缘可使用 9-slice，但不能把横线纸、方格纸和大块皱褶无脑拉伸。若要用 9-slice，请由导入设置或脚本设定正确的 Border，不能要求我手动逐张补设后才有画面。
3. 照片中的裁切区、颜色参考和纹理使用方式先读 `asset_manifest.json`。保持横线、方格的自然间距，必要时用 UV 裁切或平铺；不要把纸张拍摄边界、桌面、相机阴影误当作完整纸面。
4. 大面积纸张的形状轮廓和纹理分开处理，避免所有卡纸都出现同一条重复褶皱。毛边只需轻微自然，不做锯齿、破洞、污渍或厚重做旧。
5. 用奶油白纸面、青灰卡纸、雾紫页签和深蓝灰底形成层次。冷暖与明度只调整 UI 纸张和装饰，**不要给音乐厅与物品图片加全局滤色、染色或重新绘画**。音乐厅原图保持比例和原始透明轮廓，完整放在方格纸前面，不裁主体、不拉伸，也不要重做图中的音乐厅。
6. 阴影是轻微贴纸投影，用少量偏移层即可；不要做玻璃拟态、金属边框、霓虹发光或通用应用图标。尽量共用默认 UI 材质或少量共享材质，不要给每个对象创建一份独立材质。
7. 自定义 Shader 必须兼容当前项目现有的 UI 遮罩与渲染方式。如果使用 Shader 会引入管线、遮罩或版本兼容成本，优先改用自定义 `Graphic` / Mask / 分层图像的简单方案，不更换项目管线。

## 原游戏 PNG 的透明留白

请特别检查 PNG 的 Alpha 包围盒。原始物品图可能是 1920×1440 等大画布，实际物品只占很小一块；直接对整张图片 `preserveAspect` 会让物品小得不对。

优先使用 `asset_manifest.json` 提供的可见范围、裁切区与显示尺寸。可生成独立的导入派生 Sprite，或用父级可见区域加子级图片偏移/缩放，让实际可见物品达到规格中的大小。保留原始 PNG，不能为了减留白而破坏原图。无论采用哪种方法，都要在 Unity 中实际比较物品的可见尺寸，而不只检查 `RectTransform` 的宽高。

图片按 UGUI 的 Sprite 资源导入，保留 Alpha；UI 图片通常关闭 Mip Maps、使用合适的 Bilinear 过滤与足够大的 Max Size。不要为了统一参数批量重导整个项目，只处理本轮复制的资产。纯装饰图像关闭 `raycastTarget`；本轮是静态界面，不要顺手接入输入或交互系统。
