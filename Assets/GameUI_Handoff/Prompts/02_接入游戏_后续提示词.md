# 第二阶段：静态页面确认后再用

前提：第一阶段纸张 UI 已在我本机 Unity 中预览并确认。请保留它的布局、纸张和配色，在现有游戏项目中接入真实功能。先读取第一阶段文档、Prefab、项目现有对话/物品/存档代码，复用已有系统，不重写剧情，不引入新包，不升级 Unity。

请先只完成现有项目中已有数据能支持的内容：

1. 绑定顶部设置、地图、档案、存读档、回主菜单入口到项目现有窗口；窗口若不存在，仅创建清晰的适配接口并说明，不编造已经实现。
2. 左侧记忆/收藏页签、栏位收起展开；物品用原图自然排布。记忆物品可拖动，收藏物品不可拖出。先适配现有物品数据；不要凭概念图给物品编造剧情含义。
3. 右侧头像、说话人、正文、选项、Log、自动/快进/隐藏绑定现有对话系统。旧选项置灰、新话题高亮；复用项目已有 Yarn Spinner 版本与节点，不改正文。
4. 场景与热点、已放置物品的坐标相对于实际场景视口，不能相对于整屏纸张背景。统一处理缩放、拖放坐标、拾取与取回；场景画面保持原色。

本阶段才恢复必要的文字。默认英文，字体先沿用项目现有且清楚可读的字体；正文建议以 1920×1080 设计像素的 18—20 px 为起点，按钮约 15—17 px、小标签约 12—14 px，需看实际字形和屏幕预览校准。不要使用巨大的移动端字号、难辨识连笔字、粗马克笔体或随机下载的手写字体。字重、行距与阅读对比优先；最终字体单独确认，不因恢复文字而改变纸张布局。

只把点击区和拖动对象设为输入目标，纸张、格线和阴影不拦截；按钮的实际点击范围可大于小纸条的视觉范围。动作参数保持克制，先保证可用，不增加未经要求的装饰和演出。

请按功能逐项实现和运行验证，报告实际接通的内容及缺失的真实数据。不要把占位函数说成已经接入。三个结局、跨周目、成就、视差等仅在当前项目已有模块可复用时适配，本提示词不要求你从头补完整个游戏。
