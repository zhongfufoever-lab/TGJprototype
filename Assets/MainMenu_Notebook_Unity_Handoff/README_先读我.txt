孕育与诞生 主菜单分层素材包

本包对应你选定的无字手账版本。素材以参考成图为依据提取和重建，被遮挡的纸面已经补齐；不是原始 PSD 图层，因此纸纹、毛边及局部阴影与参考会有细微差异。

包含 23 张独立 PNG：1 张背景、22 张透明素材。
五个菜单纸条分别独立，可单独移动、隐藏和接入按钮事件。

最快使用方式
1. 将整个 MainMenu_Notebook_Unity_Handoff 文件夹放入 Unity 项目的 Assets。
2. 等待导入和编译，选择 Tools > ThatGameJam > Build Main Menu From Layers。
3. 打开本包 Generated 下新生成的 MainMenu_UI.unity。
4. 对照 Preview/Assembly_Preview.png 微调，在五个 Button 的 On Click 中连接自己的功能。

文字尚未加入。标题与按钮下预留空文字定位点，使用你项目中已经正常显示中文的字体。
不自动修改已有场景、不处理原项目的字体报错，也不包含剧情或存档逻辑。
