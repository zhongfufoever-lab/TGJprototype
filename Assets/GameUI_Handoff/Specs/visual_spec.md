# 视觉与 Unity 实施规格

## 选定方向

唯一目标图：`../Reference/selected_2C.png`。青灰卡纸、雾紫纸条、燕麦白横线纸、深靛蓝底；真实照片纸张拼贴。当前所有 UI 文本为空白，头像是匿名占位。

严格保留：左右纸板的大圆角轮廓、独立头像卡结构、空白纸条标签、中央细密方格、自然摆放的六件物品。主体边界由纸张和阴影构成，不加黑色描边，不用猛烈锯齿或夸张撕边。

不要重新设计为黑色极简界面；不要加入花草、音符、邮戳、胶带、涂鸦、厚重做旧、通用齿轮或软盘图标。

## 配色起点

| 左右青灰卡纸 | `#77898D` |

## 布局与坐标

目标图为 1672×941，布局表已按一个等比系数映射到 1920×1080，并居中。数值是近似测量，不是原设计文件导出的精确尺寸。

`layout_1920x1080.json` 中所有 `rect_xywh` 均是 **设计根容器坐标**，不是相对语义父节点坐标。可把图形都放在统一坐标根下，或将坐标换算到局部父级；不能直接套进带偏移的父节点导致重复偏移。

UGUI 固定坐标元素可使用：`anchorMin = anchorMax = pivot = (0,1)`，`anchoredPosition=(x,-y)`，`sizeDelta=(w,h)`。表内旋转值以画面顺时针为正，Unity Z 旋转要按其自身方向换算。

建议 Canvas 使用 Screen Space Overlay + Canvas Scaler，设计参考 1920×1080。将整套构图置于居中的 16:9 根容器并统一缩放；非 16:9 留边，避免分别拉伸宽高。先验收 1920×1080 与 1280×720。

中央方格纸的装饰外框约 1.25:1。它不是严格的 4:3 场景画布，不能因最早策划写了 4:3 而再次改变已选效果图。当前阶段完整 contain-fit 音乐厅 PNG；后续真实 4:3 场景相机/逻辑区域需与装饰背板分开适配，热点跟随实际场景坐标。

## 照片纸张怎么拼

| 源照片 | 用途 | 处理方向 |
|---|---|---|
| `cardstock_teal.jpg` | 外底、左右背板 | 选择不同 UV 区域；变为深靛蓝或青灰，保留纤维。圆角形状由 UI 蒙版/Graphic 实现。 |
| `ivory_crumpled.jpg` | 标题纸条、头像卡、底部说明纸、雾紫条 | 裁切不同纹理区域。长纸条不要把整张皱褶拉成长橡胶；保持纹理尺度。 |
| `ruled_crumpled.jpg` | 对话页 | 保持横线水平；用 UV 裁切或保比例映射，宁可在左右裁纹理，不要将线距压得不均匀。 |
| `graph.jpg` | 衬纸、方格纸 | 浅色用原图；深色纸可低对比度重映射，或单独叠加细方格层。 |

提供的是整幅照片，不是透明纸片 PNG。为不同大小建立可调 Prefab：PaperBackplate、PaperSlip、RuledPage、GraphMount；纹理、形状、阴影独立。纸边轻微不齐即可，不重新画粗手绘勾线。角半径参考布局表，可在 Unity 中微调。

照片已经有褶皱阴影；额外投影宜轻，约 2—6 个设计像素偏移，深色低透明度，不叠出厚黑边。方格参考间距约 28—32 个设计像素，细线约 1 像素，低对比。横线参考间距约 34—36 像素。照片的固有印刷线优先于另画叠线，避免双重网格。

## 原美术的透明边距

各 PNG 保留用户原文件的透明画布。`asset_manifest.json` 提供 `alpha_bbox_top_left_xyxy`，坐标是左上原点的 `[left,top,right,bottom]`。Unity Sprite Rect 以左下为原点：

`Rect(left, imageHeight-bottom, right-left, bottom-top)`

不要对 1920×1440 整幅 PNG 直接设置一个很小的 Image 并以为可见物体会占满。可用派生 Sprite Rect，或让完整图片相对父级按 alpha bbox 偏移缩放。保留原文件，不覆盖用户美术。布局表中 `original_art` 的尺寸描述的是 **可见物体盒**。

参考中的钱包、门票和书是生成示意，不能要求 Codex把用户原图改成示意中的形状。当前原资产只有打开的钱包，直接使用打开版本。画像未提供，暂用独立圆形头部与肩膀形状，不新增角色设定。

## 第一阶段验收

- 构成多个独立 UI 对象与 Prefab；整张效果图仅作对照层，最终关闭且不依赖它显示页面。
- UI 保持无字，空白纸条和阅读面保留；不引入随机字体。
- 左右圆角底板、对话头像卡、格纸和六件物品的布局符合选中参考。
- 原音乐厅完整等比，原美术颜色不变；物品可见大小自然。
- 装饰层不拦截输入；静态阶段全部 `raycastTarget=false`，交互接入后只开放实际点击/拖动目标。
- 在 1920×1080、1280×720 比例一致；非 16:9 不裁主要内容。
- 只在本轮新增目录与新展示场景工作，不覆盖既有场景、包、Unity 版本或剧情系统。

本交付包尚未在用户本机 Unity 项目执行。只做文件完整性和规格一致性检查，不称为 Unity 运行验证。
